# Agent Roles

- Incident Orchestrator: creates scoped tasks, runs specialists, merges results, and records completion.
- Connectivity Agent: traces bounded process and utility paths.
- Safety Context Agent: retrieves designed safeguards while avoiding availability claims.
- Maintenance and Memory Agent: reviews open maintenance findings, historical incidents, and active memory with explicit provenance distinctions.
- Evidence Validator: deterministic validation component that accepts or rejects structured findings.
