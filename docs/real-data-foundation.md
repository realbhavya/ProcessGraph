# Real Data Foundation

Milestone 11 supports the Rieth Tennessee Eastman benchmark from Harvard Dataverse (DOI `10.7910/DVN/6C3JR1`). The source archive is not redistributed. The downloader uses the Dataverse Data Access API and writes a SHA-256 receipt. The importer reads the original RData files or schema-equivalent CSV exports, enforces 55 required columns, quality-checks identities and numeric values, and writes normalized long-form observations to PostgreSQL.

This is real published benchmark data generated by a high-fidelity chemical-process simulation. It must not be described as live data from a commercial plant. A future OPC UA milestone will replay these genuine benchmark observations as a live industrial data stream.
