# Synthetic Data Declaration

The default ProcessGraph Sentinel dataset is entirely synthetic and was created for a software demonstration.

It does not represent a real plant, real incident, real person, real operating procedure, or verified engineering recommendation. Equipment tags, measurements, maintenance findings, people, teams, incidents, actions, outcomes, procedures, safeguards, and memories are fictional.

The dataset must not be used for real operating or safety decisions. New data added to the project must be public, synthetic, or project-owned and appropriately licensed.
